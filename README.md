## ✨ What is ATLAS?

ATLAS is an **advanced PC assistant** that transforms how you interact with your computer. Think of it as an AI companion that can see your screen, remember your preferences, learn from your actions, and automate complex workflows.

## 🚀 Core Features

### 🧠 **AI Main Brain**
- Powered by Google Gemini API
- Processes natural language requests
- Orchestrates complex multi-step tasks

### 🎯 **Live Fix Mode**
- Real-time screen analysis and interaction
- Visual problem-solving assistance
- Automated troubleshooting

### 🔧 **Agent Framework**
- Visual workflow builder with drag-and-drop canvas
- Custom agent and tool creation
- Automated task execution

### 🧠 **Memory System**
- Long-term and short-term memory
- User preference learning
- Ability storage and retrieval

### 👁️ **Learning & Observation**
- Screen recording and analysis
- User action learning
- Automated ability generation

### 🖥️ **VM Learning**
- Safe training environment
- Isolated skill development
- Risk-free automation learning

### 🎮 **GUI Control**
- Voice command integration
- Automated interface interaction
- Multi-window management

## 🎯 Use Cases

- **Screen-based Learning**: Teach ATLAS your workflows by demonstration
- **Workflow Automation**: Create visual workflows for repetitive tasks
- **Real-time Troubleshooting**: Get instant help with error messages and system issues
- **Custom Agent Development**: Build specialized AI assistants for specific domains
- **Screen Tracking**: Keep track of work you did by letting it observe

## ⚠️ Project Status

**This is an unfinished proof of concept** developed for the **Google Gemini API Developer Competition**. The project showcases innovative AI-computer interaction concepts but is not production-ready.

**Last Updated**: August 12, 2024

## 🛠️ Technology Stack

- **AI Model**: Google Gemini API (1.5-pro, 1.5-flash)
- **GUI Framework**: Tkinter, CustomTkinter
- **Automation**: PyAutoGUI, OpenCV
- **Virtualization**: VirtualBox integration
- **Memory**: JSON-based persistent storage

## 📋 Requirements

- Python 3.8+
- Google Gemini API key
- VirtualBox (for VM Learning)
- Windows OS (primary target)
